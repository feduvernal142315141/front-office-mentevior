# Alcance de cambios según el chat

- Los chats generales de una sesión no pueden modificar ningún repositorio específico si el usuario no indica explícitamente en cuál repositorio deben realizarse los cambios.
- La existencia de varios repositorios accesibles, cercanos o asociados a la misma sesión no autoriza a elegir uno por inferencia.
- Si el usuario no identifica el repositorio destino, se debe solicitar esa información antes de modificar archivos o ejecutar operaciones que alteren un proyecto.
